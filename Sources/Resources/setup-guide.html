YTBar Setup Guide

YTBar needs a Google API OAuth client to access your YouTube Music library, playlists, and liked music. This guide walks you through creating one.

Important: You need a Google account. A YouTube Premium subscription is recommended for ad-free audio streaming but is not strictly required.

1. Create a Google Cloud Project

  1. Go to the Google Cloud Console — New Project
  2. Enter a project name (e.g., YTBar)
  3. Click Create
  4. Make sure the new project is selected in the top-left project dropdown

2. Enable the YouTube Data API v3

  1. Go to YouTube Data API v3 in the API Library
  2. Click Enable
  3. Wait for it to finish enabling

3. Configure the OAuth Consent Screen

  1. Go to OAuth consent screen
  2. Select External user type, then click Create
  3. Fill in the required fields:
    • App name: YTBar
    • User support email: your email
    • Developer contact: your email
  4. Click Save and Continue
  5. On the Scopes page, click Add or Remove Scopes
  6. Search for youtube and check .../auth/youtube (full YouTube access)
  7. Click Update, then Save and Continue
  8. On the Test users page, click Add Users
  9. Add your Google account email, click Save and Continue
Note: Since the app stays in "Testing" mode, only the test users you add can sign in. This is fine for personal use — you don't need to publish or verify the app.

4. Create OAuth Client Credentials

  1. Go to Credentials
  2. Click + Create Credentials → OAuth client ID
  3. Application type: TVs and Limited Input devices
  4. Name: YTBar
  5. Click Create
  6. You'll see your Client ID and Client Secret — copy both

5. Enter Credentials in YTBar

  1. Open YTBar → Settings tab
  2. Paste the Client ID and Client Secret into the fields
  3. Click Save
  4. Click Sign In with Google
  5. A browser window opens — enter the device code shown in the app
  6. Grant access to your YouTube account

Troubleshooting

Sign-in says "Access blocked" or "App not verified"

  • Make sure you added your Google email as a Test user in step 3
  • If you see a "This app isn't verified" warning, click Continue (it's your own app)

Library/playlists don't load

  • Verify the YouTube Data API v3 is enabled in your project
  • Check that you selected TVs and Limited Input devices as the application type

"Quota exceeded" errors

  • YouTube Data API has a daily quota of 10,000 units. Normal usage won't hit this. If you do, wait until midnight Pacific Time for it to reset.
